simulating M. Morris Mano's Basic Computer in CPU Sim 4.0.11.

## Contents
- machine/BasicComputer.cpu: machine design and fetch routine (Practicals 1-2)
- programs/: assembly programs for Practicals 3-11
- screenshots/: output screenshots

## Practicals
1. Create a machine based on the Basic Computer
2. Fetch routine of the instruction cycle
3. ADD two user-entered numbers
4. SUBTRACT two user-entered numbers
5. Logical operations (AND, OR, NOT, XOR, NOR, NAND)
6. Memory-reference instructions (ADD, LDA, STA, BUN, ISZ)
7. Register-reference instructions (CLA, CMA, CME, HLT)
8. Register-reference instructions (INC, SPA, SNA, SZE)
9. Register-reference instructions (CIR, CIL)
10. Sum of integers until a negative number is read
11. Sum of integers until zero is read

## How to run
1. Install Java 8 with JavaFX and CPU Sim 4.0.11
2. Open BasicComputer.cpu (File > Open machine)
3. Open a program from programs/ (File > Open text)
4. Press Ctrl+2 to assemble and load, then Ctrl+R to run
